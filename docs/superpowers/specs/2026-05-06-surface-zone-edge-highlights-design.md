# 표면 구역 경계선 강조 표시(Surface Zone Edge Highlights) 설계 사양서

**날짜:** 2026-05-06
**상태:** 초안
**범위:** `app/frontend` (Three.js 렌더링 최적화)

---

## 1. 개요

이 문서는 3D 뷰어에서 건물 표면 구역을 시각화할 때, 구역 내부의 면 경계선은 제외하고 **구역의 전체 외곽 경계선(Outer Boundary Edges)**만 정교하게 강조 표시하는 기술적 설계를 다룹니다.

## 2. 문제 정의

현재 단순히 선택된 모든 면의 경계(Edges)를 그리면, 구역 내부의 인접한 면들 사이의 선까지 모두 그려져 시각적으로 복잡해 보입니다(격자 무늬 발생). 분석가에게 필요한 것은 구역의 '덩어리'를 보여주는 깨끗한 외곽선입니다.

## 3. 해결 방안: 경계선 추출 알고리즘

구역 내에 포함된 면(face)들의 집합에서 외곽선만 추출하기 위해 다음 로직을 적용합니다.

### 3.1 공유 에지 제거 (Shared Edge Removal)
1. 구역 내 모든 면의 모든 에지(변)를 수집합니다.
2. 각 에지에 대해, 해당 에지를 공유하는 면의 개수를 계산합니다.
3. 구역 내에서 **정확히 하나의 면에만 속한 에지**가 바로 외곽 경계선입니다.
4. 두 개의 면에 의해 공유되는 에지는 내부 선이므로 무시합니다.

### 3.2 구현 단계
- **입력:** 구역에 포함된 `face_ids`, 전체 메시의 `index` 및 `position` 버퍼.
- **처리:** 
    - 에지를 키(예: `min(v1,v2)-max(v1,v2)`)로 하는 해시 맵을 사용하여 카운팅합니다.
    - 카운트가 1인 에지들만 모아 `BufferGeometry`를 생성합니다.
- **출력:** `LineSegments` 객체.

## 4. 렌더링 스타일링

- **두께:** `THREE.LineBasicMaterial`은 브라우저 제약으로 두께 조절이 어려우므로, 필요시 `MeshLine` 라이브러리를 검토하거나 픽셀 단위로 일정한 시각적 두께를 제공하는 셰이더를 사용합니다.
- **가시성:** 건물의 다른 부분에 가려지지 않도록 `depthTest` 설정을 조정하거나, 구역 색상에 맞춰 발광(emissive) 효과를 추가합니다.

## 5. 성능 고려 사항

- **캐싱:** 구역의 `face_ids`가 변경될 때만 경계선 지오메트리를 재계산합니다.
- **워커(Worker):** 복잡한 메시에서 구역이 매우 큰 경우, 메인 스레드 차단을 방지하기 위해 웹 워커에서 계산하는 것을 고려합니다.

## 6. 사용자 경험 (UX)

- 사용자가 구역을 편집(면 추가/제거)할 때, 외곽선이 실시간으로 부드럽게 업데이트되어 구역의 형태 변화를 즉각적으로 인지할 수 있게 합니다.
- 시뮬레이션 결과 위에 이 깨끗한 외곽선이 얹어짐으로써 데이터 시각화의 품질이 향상됩니다.
