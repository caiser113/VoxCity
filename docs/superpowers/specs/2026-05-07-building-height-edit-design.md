# 건물 높이 편집(Building Height Edit) 설계 사양서

## 요약

사용자가 2D 평면 편집기에서 하나 이상의 기존 건물을 선택하고 수치 입력을 통해 높이를 수정할 수 있는 기능을 추가합니다. 이 기능은 건물을 완전히 삭제하고 다시 그리는 방식이 아닌, 속성 값을 직접 업데이트하는 효율적인 워크로드를 지원합니다.

## 목표

- 2D 지도에서 건물 높이를 시각화합니다.
- 클릭 또는 폴리곤 선택을 통해 하나 이상의 건물을 선택합니다.
- 선택된 건물에 대해 새로운 높이(및 선택적으로 최소 높이)를 설정합니다.
- 기존의 편집 버퍼 시스템을 사용하여 수정을 미리 보고 커밋(commit)합니다.
- 모델 재생성 시 수정된 높이가 물리적으로 반영되도록 합니다.

## 아키텍처 결정

| 결정 사항 | 선택 | 근거 |
| --- | --- | --- |
| 시각화 | 2D 지도의 건물 풋프린트 위에 텍스트 라벨 표시 | 편집 중인 건물의 현재 높이를 확인하는 가장 명확한 방법입니다. |
| 편집 단위 | 건물 수준 (풋프린트 기반) | 그리드 셀 단위보다 사용자의 멘탈 모델에 더 잘 부합하며 데이터 일관성을 유지하기 쉽습니다. |
| 수정 방식 | 명시적 'Apply' 버튼이 있는 버퍼링 방식 | 실수로 값을 변경하는 것을 방지하고, 다른 편집(추가, 삭제)과 동일한 'Update 3D model' 흐름을 유지합니다. |
| 다중 선택 | 클릭 누적 및 폴리곤 포함 선택 | 대규모 단지나 거리 전체의 높이를 한 번에 수정하는 작업을 지원합니다. |

## 데이터 흐름

### 1. 프런트엔드 선택 및 편집

`EditTab`은 현재 선택된 건물 ID 세트와 입력된 높이 값을 관리합니다.

```ts
interface HeightEdit {
  type: 'set_height';
  ids: string[];        // GeoJSON 피처 ID
  height: number;
  min_height?: number;
}
```

- 사용자가 건물 모드에서 'Height' 도구를 선택합니다.
- 2D 지도에 건물 높이 라벨이 나타납니다.
- 클릭이나 드래그로 건물을 선택하면 강조 표시됩니다.
- 높이 값을 입력하고 'Buffer Edit'을 클릭하면 `pendingEdits` 리스트에 추가됩니다.

### 2. 백엔드 처리

`POST /api/edit` 엔드포인트는 `set_height` 유형의 명령을 수신합니다.

- 백엔드는 클라이언트가 보낸 ID를 내부 그리드 좌표로 매핑합니다.
- `voxcity.buildings.heights` 어레이의 해당 셀 값을 업데이트합니다.
- `regenerate_voxels`를 호출하여 3D 복셀 모델을 다시 빌드합니다.
- 업데이트된 3D 피규어 JSON을 프런트엔드로 반환합니다.

## UI/UX 세부 사항

- **라벨 제어:** 높이 라벨은 건물이 너무 많아 복잡할 경우를 대비해 토글(On/Off)이 가능해야 합니다.
- **강조 표시:** 선택된 건물의 외곽선 색상을 변경하여 편집 대상임을 명확히 합니다.
- **유효성 검사:** 높이는 양수여야 하며, 최소 높이는 총 높이보다 작아야 합니다.

## 테스트 계획

- **단일 편집:** 건물 한 개의 높이를 변경하고 3D 모델에서 물리적 변화를 확인합니다.
- **그룹 편집:** 여러 건물을 동시에 선택하여 동일한 높이로 변경합니다.
- **실행 취소(Undo):** 버퍼링된 높이 수정을 취소했을 때 라벨과 선택 상태가 복구되는지 확인합니다.
- **데이터 일관성:** 높이 수정 후 모델을 저장하고 다시 로드했을 때 변경된 높이가 유지되는지 확인합니다.
